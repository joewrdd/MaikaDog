# Contributing to Maika

Thanks for wanting to poke at the dog. This is a small, personal project, so
the process is light — but a few things about this codebase are genuinely
non-obvious, and knowing them up front will save you an afternoon.

## What you need

- **macOS 13 or newer.** The app is macOS-only and cannot be built or run
  anywhere else.
- **Flutter 3.44.0** (Dart 3.12). Older versions will not resolve.
- **Xcode** with the command line tools, and **CocoaPods** (`sudo gem install
  cocoapods`).

No Apple Developer account and no paid anything is required. There is no team
ID baked into the project, so cloning and running works out of the box.

```bash
git clone https://github.com/joewrdd/MaikaDog.git
cd MaikaDog
flutter pub get
flutter run -d macos
```

## Before you open a pull request

```bash
dart format lib test
flutter analyze     # must print "No issues found!"
flutter test        # must be all green
```

CI runs exactly these three, plus a release build. Its format check covers all
of `lib` and `test`, so run it the same way rather than only on your own files.

## Things that will surprise you

**Everything is drawn in code.** There are no image assets and no sprite
sheets. Every dog, fit and room is Flutter `CustomPainter` paths pushed through
the hand-ink layer in `lib/characters/core/sketch.dart`. The PNGs in `art/` are
output *from* the engine, not input to it — they are regenerated by the tests.
A pull request that adds a PNG to draw something will be sent back with
affection.

**Swift Package Manager is deliberately disabled** in `pubspec.yaml`
(`enable-swift-package-manager: false`). One of the plugins has no SPM support
and re-enabling it breaks the build. Please don't "fix" it.

**The code has no comments, by house style.** Rationale lives in documentation
like this file, not in the source. Match what is already there.

**Tests render real frames.** `flutter test` writes preview images to
`build/maika_previews/` and `build/house_previews/`. If you change a drawing,
look at the output — that is the actual review. The render tests walk every
accessory and every house, so a new one that fails to draw shows up
immediately. The committed PNGs in `art/` are copied there by hand when a
drawing changes; nothing writes to `art/` automatically.

**There is a second entrypoint** for looking at characters in bulk:

```bash
flutter run -d macos -t lib/characters/gallery/gallery_main.dart
```

**Nothing may touch the network.** Maika's core promise is that nothing leaves
your Mac. `test/no_network_test.dart` enforces this and will fail the build if
a networking API or a new dependency appears. If you have a genuine reason to
add a dependency, say so in the pull request.

## Adding a fit or a room

Fits are drawn three times — front, three-quarter and profile — because the
turn swaps between separate drawings the way a cel animator would cheat it.
All three live in `lib/characters/dogs.dart`. Rooms live in
`lib/characters/houses/`, one file each, registered in `houses.dart`.

Keep new content **original**. Loving nods to things you like are welcome;
recognizable logos, character names, and trademarks are not, since everything
here ships under a permissive license to everyone.

## Reporting bugs

Use the issue templates. The app version is at the bottom of her dashboard
(open it from the menu bar paw). For anything security-related, see
[SECURITY.md](SECURITY.md) instead.
